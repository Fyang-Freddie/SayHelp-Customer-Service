# SayHelp repository workflow

- This project's GitHub remote is `https://github.com/Fyang-Freddie/SayHelp-Customer-Service.git`.
- After a project change is complete and verified, commit it and push it to this GitHub repository. Use `main` or a reviewed feature branch as appropriate; do not leave completed changes only in a local worktree.
- Never commit `.env`, API keys, virtual environments, or other local credentials.
- Keep the chapter 1 development record in `dev-notes/ch01.md` when continuing chapter 1 work.
